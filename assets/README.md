# assets

Put your photo here as **sky.jpg** (or .png / .webp — then update the `src` in `index.html`).

It's used by the home-page ID-card avatar. A portrait crop centered on your face works best:
the image uses `object-fit: cover`, cropped to a ~1 : 0.62 card and anchored to the top.

If no image is present, the card gracefully falls back to the "SP" monogram.
